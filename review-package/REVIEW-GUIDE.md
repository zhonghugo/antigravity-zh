# Antigravity 汉化插件 - 代码审查指南

## 项目概述
为 Google Antigravity 桌面客户端注入中文翻译的零依赖 Python 安装器。
通过解包 app.asar → 注入翻译引擎 → 重新打包实现汉化。

## 审查文件说明

| 文件 | 行数 | 审查重点 |
|---|---|---|
| `install.py` | 512 | 安装/还原逻辑、文件操作安全性、注入幂等性、路径处理 |
| `asar.py` | 287 | asar 格式解析/打包正确性、offset 计算、大文件处理 |
| `engine.js` | 804 | DOM 翻译引擎、MutationObserver 性能、正则匹配正确性、XSS 风险 |
| `zh_cn.json` | 1579条 | 翻译质量、词条覆盖度、是否有错误翻译 |
| `README.md` | 112 | 文档准确性 |
| `SKILL.md` | 59 | 技能描述 |

## 重点审查方向

### 1. 安全性
- install.py 是否有路径遍历、命令注入风险
- asar.py 解包时是否校验文件路径（防止 zip slip 类攻击）
- engine.js 注入 DOM 时是否有 XSS 风险（翻译内容是否会被当 HTML 解析）
- 是否会修改 app.asar 以外的文件

### 2. 正确性
- asar.py 的 header 解析、offset 计算是否正确（已与官方 @electron/asar 交叉验证）
- 翻译引擎的匹配优先级（长词条优先、精确匹配优先）
- 还原功能是否能完全恢复官方原版
- 幂等性：重复安装是否会出问题

### 3. 性能
- MutationObserver 是否会导致页面卡顿（debounce？批量处理？）
- 翻译引擎遍历 DOM 的效率
- 1579 条词典的正则匹配性能

### 4. 翻译质量
- 是否有明显的机翻痕迹
- 技术术语是否统一
- 是否有遗漏的关键界面

### 5. 已知设计决策
- 纯 Python 实现，零外部依赖（不依赖 Node.js/npm/asar CLI）
- 修改本地 app.asar，非官方语言包
- 官方升级会覆盖补丁，需重新安装
- macOS 重签名可能失败（不影响运行，仅 Gatekeeper 警告）

## 测试建议
1. 全新安装 → 验证界面汉化
2. 重复安装 → 验证幂等性
3. 还原 → 验证完全恢复
4. 官方升级后重装 → 验证兼容性
